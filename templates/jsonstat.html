About JSON-stat 2

JSON-stat is a cube-oriented JSON format for statistical data. SPARQL Bridge turns every cube cell with a value into a W3C RDF Data Cube observation, including coded dimensions, measure value, optional status, and unit attributes. Cells without values remain available as JSON-stat compatibility records.

Statistics Finland dimensions are enriched primarily from a local, pre-parsed export of the open classification API only when both the dimension identifier and category code match exactly. Matched categories receive additional SKOS labels, hierarchy, notes, and links to the API; unmatched values remain local SKOS concepts with their original JSON-stat metadata. Network fallback is disabled by default, so classification enrichment does not add upstream API requests to dataset loading.
